# Crust — Project Design Context

## Design Context

### Users
Frontend developers (Astro-first, React-second) integrating notifications into their
sites; the end users of those sites see the toasts. Docs site visitors are developers
evaluating the library in under a minute — the playground must sell it instantly.

### Brand Personality
Warm, crafted, opinionated. The baked-goods brand (crust, oven, fresh bread) played
straight and elegant — never cutesy, never toy-ish.
Anti-references: glassmorphism, iOS-clone toasts, sileo's bump-on-expand artifact,
bouncy/elastic motion.

### Aesthetic Direction
Warm matte paper/ceramic surfaces: oklch warm-tinted neutrals (hue ~75), opaque —
no blur, no translucency. Constant 10px radius across all states. Semantic color
(herb green / brick red / slate blue) lives ONLY in stroke-drawn icons; text stays
neutral ink. The library inherits the host site's font. The docs site uses a
distinctive, non-reflex typeface chosen via the font-selection procedure.
Motion: ease-out-quint, nothing over 320ms, organic deceleration, zero overshoot.
Signature interaction: a capsule that morphs into a card as one continuous surface.

### Design Principles
1. **One surface, growing** — never panels stacking on panels.
2. **Color is the 10%** — surfaces stay neutral; icons carry meaning.
3. **Nothing waits** — exits faster than entrances; interaction is never blocked.
4. **The host site's voice wins** — fonts inherit, everything themeable via `--crust-*`.
5. **Reduced motion is a first-class theme**, not a degraded fallback.
